# Thư mục Nhạc nền Tĩnh (`src/data/audio/`)

Thả trực tiếp các tệp nhạc `.mp3`, `.wav`, `.ogg`, `.m4a`, `.flac` vào thư mục này — ứng dụng sẽ tự động nhận diện và thêm vào **Danh sách phát** (ưu tiên lên đầu danh sách) mà không cần sửa code.

Ngoài ra, ứng dụng vẫn tích hợp sẵn **10 bản piano không lời** (60–82 BPM) và hỗ trợ nút **+ Thêm nhạc MP3** trực tiếp trên trình duyệt (lưu trong IndexedDB).
